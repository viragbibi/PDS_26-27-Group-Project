Music streaming platforms generate large-scale data about listening behavior, popularity trends, and artist impact. 
Your task is to transform a raw “All-time most streamed artists” dataset into an analysis and/or tool that helps someone answer practical questions such as:
• Which artists dominate streaming?
• Where are they from?
• Are there identifiable patterns by genre?
•Can we build an exploration or recommendation-style insight based on the dataset? 
You will work through a full Data Science workflow: loading and cleaning the dataset, exploring it, visualizing it (with static and interactive visualizations), 
and tackling advanced tasks (e.g., web scraping for enrichment or geo/image features usable from external sources).
